# Preliminary computational record

**Author:** Romeo Mugnier de Almeida  
**Initial public release:** 25 July 2026

This repository records two AI-assisted computational findings:

1. A graph isomorphic to `CAT(182,3)` is claimed to be
   \(C_{12}\)-induced-saturated.

2. The Coxeter graph is claimed to be
   \(C_{14}\)-induced-saturated.

The repository contains a preliminary manuscript, exact graph descriptions,
machine-readable witness certificates, verification programs, stored outputs,
and SHA-256 manifests.

The mathematical claims are supported by exhaustive computational
verification, but the manuscript has not been peer reviewed. The novelty and
priority of the observations have not yet been established. No claim of
minimality is made.

This initial release is intended to document that the enclosed manuscript,
constructions, certificates, and verification materials were publicly
available from this repository by the release date.

## Contents

- [`paper/`](paper/) — preliminary manuscript and LaTeX source
- [`C12/`](C12/) — CAT(182,3) C12 verification materials
- [`C14/`](C14/) — Coxeter graph C14 verification materials

## Reproducibility

Each communication bundle contains its own README, execution instructions,
stored outputs, and SHA-256 manifest.

Stored output files are not substitutes for rerunning the supplied programs.

SHA-256 hashes establish file identity; they do not by themselves prove the
graph-theoretic claims.

## AI assistance

AI tools assisted in candidate generation and in drafting portions of the
verification software and exposition. The supplied certificates and programs
are included so that the claims can be checked independently.
